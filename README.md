# numlo

Short videos about numbers: prices, currencies, inflation, indexes — one figure per video, with a chart and the source.

- Russian channel: https://www.youtube.com/@numlo_ru
- English channel: https://www.youtube.com/@numlo_en

The videos are produced by an automated pipeline (script, voice-over, graphics and upload are machine-generated),
every figure comes from a public data source linked in the video description, and each video is marked as AI-generated.

This repository hosts the public pages for the `numlo` YouTube uploader app: this homepage and the
[privacy policy](PRIVACY.md) and [terms of service](TERMS.md).
